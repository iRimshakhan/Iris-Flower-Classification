
# Iris Flower Classification using Logistic Regression

## Project Overview
This project implements a complete Machine Learning workflow to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

The project uses Logistic Regression for multiclass classification and explores the dataset through data cleaning, preprocessing, visualization, model training, and evaluation.

## Objectives
- Load and explore a CSV dataset using Pandas.
- Identify missing values, duplicates, and potential outliers.
- Perform appropriate data preprocessing.
- Visualize data distributions and feature relationships.
- Encode the target labels and train a Logistic Regression model.
- Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
- Compare actual and predicted species with class probabilities.
- Inspect model coefficients to understand its learned relationships.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Logistic Regression

## Project Workflow
1. Data loading and inspection
2. Data quality checks
3. Outlier detection and investigation
4. Exploratory Data Analysis
5. Data preprocessing
6. Model training
7. Model evaluation
8. Prediction probability analysis

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Place the dataset in the project directory.
4. Run the Python script:
   `python iris_classification.py`

## Dataset
The project uses a CSV file containing four flower measurements and the species label.
